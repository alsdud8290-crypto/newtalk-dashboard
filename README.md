# 뉴토크 코리아 경영 대시보드

경영지원팀 1단계: 경영 현황 대시보드, 데이터 입력, 엑셀 업로드(과거 데이터 이관), 사용자·권한 관리.
생산팀·서비스팀 메뉴는 권한 구조만 갖춘 상태이며 화면은 다음 단계에서 구현합니다.

## 실행

Node.js 22.13 이상이 필요합니다. 별도 DB 설치는 필요 없습니다(내장 SQLite).

```bash
npm install
cp .env.example .env      # Claude API 키 등 설정 (선택)
npm start                 # http://localhost:3000
```

- 첫 로그인: `admin` / `admin1234` → 로그인 직후 비밀번호 변경 화면이 뜹니다.
- 화면 확인용 샘플 데이터: `npm run seed:demo` (데이터가 비어 있을 때만 동작, 거래처명에 "(샘플)" 표시)
- 데이터는 `data/dashboard.db` 파일 하나에 저장됩니다. 이 파일을 복사하면 백업됩니다.

## 기능

| 메뉴 | 내용 |
|---|---|
| 경영 현황 대시보드 | 당월·분기·연간 누적 매출, 연간 목표 달성률(원형), 산업 분야별·제품 시리즈별 매출 비중(원형), 매출 추이·매출 구성(제품·상품·용역·영업외수익)·지출 구성(상품 매입·판관비·영업외비용·원재료·노무비·경비), 미수금 총액(직전·전년 동기 대비), AI 분석 코멘트. 분기/월 전환 가능 |
| 월별 실적·목표 입력 | 연간 목표매출액, 월별 제품/상품/용역 매출·영업외수익, 상품 매입·판관비·영업외비용·원재료 매입·노무비·경비, 미수금 총액(월말 잔액). 손익계산서·제조원가명세서 엑셀(.xls)을 올리면 그 달 칸에 자동 입력 |
| 매출 내역 (판매처) | 판매처·산업 분야·제품 시리즈별 매출 건. 매출자료 CSV(매출자료_YYYYMM.csv)를 올리면 자동 입력, 같은 ID는 덮어씀 |
| 엑셀 업로드 | 양식 다운로드, 기존 엑셀 그대로 업로드(열 이름 자동 인식), 미리보기 후 저장 |
| 대시보드 내보내기 | 카드별 이미지(⬇), 화면 전체 PDF, 대시보드 수치 엑셀 |
| 엑셀 형식 (회사 "경영지원 관리") | 모든 ⬇ 엑셀 내려받기가 회사 양식으로 나옴: 달마다 회사 양식 시트(미수금 현황 합계=미수금 총액, 매입 지출=상품·원재료 매입, 경비 지출=경비, 기타 지출=판관비 — 회사 원본 제목인 외상매출금·외상매입금·미지급비용으로 된 파일도 업로드 가능) + 같은 서식의 상세 시트. 이런 파일을 엑셀 업로드에 올리면 해당 화면에 반영. 각 화면의 ⬇ 내려받기에서 전체·연간·분기·월 단위로 받을 수 있고, 기간 파일을 다시 올리면 그 기간만 교체 |
| 단가 (ITB2026에서 옮겨 옴) | 부품별 비교(뉴토크 기준값 = 단가표 기준단가, 기준값 칸을 두 번 눌러 직접 수정, 출장지별 평균·최저·최고), 출장지별 비교(기준값 대비 평균 차이율), 부품 단가 데이터 업로드(CSV — 회사 "부품 및 단가리스트" [부품] 시트를 CSV로 저장한 그대로 읽음 / 출장지별 단가 CSV), 신규 부품 등록(분류·파트넘버·품목·적용모델·기준단가 직접 입력 + 엑셀 일괄 등록). 같은 파트넘버는 새 내용으로 덮어씀. 처음 실행 시 가상 값(VX…)만 들어감 |
| 생산팀 (ITB2026에서 옮겨 옴) | 생산 대시보드(납기 임박, 목표 대비 달성률·부족치, 월별/분기별 생산량+전년·수주량, 연간 목표 진행·연말 예상, 모델별, 납기 준수율, 미출고 현황, 판매 실적 기준 바꿔 보기·교차 필터), 제조내역·수주 내역 목록과 엑셀, 일련번호 조회(11개 항목), 납기 캘린더(처리 상태·검색), 제조내역 엑셀 업로드(추출 → 확인·수정 → 저장, 같은 일련번호는 최신 값으로 갱신), 업로드 이력. 처음 실행 시 가상 데이터(작년·올해) |
| 서비스팀 (ITB2026에서 옮겨 옴) | 서비스 대시보드(출장 횟수·유상/무상·월별, 한국 지도 시·도/시·군, 지역 순위, 교체 부품 순위+현재 단가, A/S 모델 순위, 담당자 비중), 출장보고서 목록·상세, 직접 입력(중복 기준: 출장 시작일+요청처). 지도 경계: 통계청(2013). 처음 실행 시 가상 데이터(작년·올해) |
| PDF 업로드 (ITB2026에서 옮겨 옴) | 수주서 PDF(생산 → 수주 내역·판매 실적), 출장보고서 PDF(서비스). 추출 → 확인·수정(잘린 값 …, 시·도 고르기) → 저장. 글자 위치 읽기는 원본(pdfplumber)과 같은 결과인지 회사 샘플 PDF로 확인. 샘플 파일은 samples/에만 두고 Git에 올리지 않음 |
| 권한 | 팀별 열람/수정 + 직책. 경영지원팀·대표·관리자 = 모든 권한, 생산·서비스·겸직 = 자기 팀 열람, 팀장만 수정 (화면·API 모두) |
| 사용자·권한 관리 | [샘플 직원 추가] 버튼(화면 확인용 13명), 사용자 등록, 부서별 기본 권한, 사람별 메뉴 권한 켜기/끄기, 계정 중지, 비밀번호 초기화 |

### 권한

| 부서 | 기본 권한 |
|---|---|
| 경영지원팀 · 대표 · 관리자 | 전체 (관리자 페이지 포함) |
| 생산팀 | 생산팀 메뉴만 |
| 서비스팀 | 서비스팀 메뉴만 |
| 생산·서비스 겸직 | 생산팀 + 서비스팀 |

관리자 페이지에서 사람마다 개별 조정할 수 있습니다. 권한은 서버에서도 검사합니다(메뉴만 숨기는 방식이 아님).

### AI 분석 코멘트

`.env`에 `ANTHROPIC_API_KEY`를 넣으면 Claude(claude-opus-5-5)가 선택 기간의 현황 / 부족한 점 / 다음 기간 개선점을 작성합니다.
키가 없거나 호출이 실패하면 규칙 기반 자동 요약으로 대신 표시합니다(화면에 출처 표시). 결과는 기간별로 저장되며 [다시 분석]을 눌러야 새로 생성됩니다.

### 계산 기준

- 월별 매출이 비어 있는 달은 매출 내역 합계를 매출로 사용합니다(화면에 안내 표시).
- 목표 페이스: 연간 목표 × 경과 개월 ÷ 12. 진행 중인 달은 일 단위로 안분합니다.
- 추정 손익 = 매출 − (상품 매입 + 원재료 매입 + 경비 + 기타 지출). 회계상 영업이익과 다를 수 있습니다.
- 미수금 경과일은 청구일 기준, 오늘 날짜 기준입니다.

## 배포 (GitHub + Render 무료 + Turso 무료)

- **Render 무료 서버**: 서버 실행. 15분 동안 접속이 없으면 절전되고, 다음 첫 접속은 약 1분 걸립니다.
- **Turso 무료 DB**: 데이터 보관. Render 무료 서버는 재시작 때 파일이 지워지므로 데이터는 Turso에 저장합니다.

1. [turso.tech](https://turso.tech) 가입 → 데이터베이스 생성(지역: Tokyo 권장) → 데이터베이스 주소(`libsql://...`)와 토큰을 복사합니다.
2. render.com → **New → Blueprint** → `newtalk-dashboard` 저장소 → Connect.
3. 환경변수 입력: `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`, `INITIAL_ADMIN_PASSWORD`(최초 admin 비밀번호), `ANTHROPIC_API_KEY`(선택).
4. 배포가 끝나면 `https://<서비스명>.onrender.com` 에 admin으로 로그인 → 비밀번호 변경 → 관리자 페이지에서 직원 등록.

- GitHub `main` 브랜치에 올리면 자동으로 다시 배포됩니다.
- Turso가 연결되지 않은 상태로 배포되면 화면 왼쪽에 "데이터가 재시작 시 삭제됨" 경고가 표시됩니다.
- 로컬(이 PC)에서는 Turso 설정 없이 `data/dashboard.db` 파일에 저장됩니다.
- 운영 환경에서는 로그인 5회 실패 시 10분 잠금, HTTPS 전용 쿠키, 보안 헤더가 적용됩니다.
